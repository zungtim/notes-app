# 关系图连线呈现

当前 KnowledgeGraph 使用纯几何 edge-routing.js 绘制圆角正交线。对齐节点直接连接，偏移连接优先在附近通道绕开卡片；同一侧多条连接分配独立端口。明显向上返回的长延伸关系可走外围通道。图中的方向和关系类型只来自已保存的 links，路由不写入笔记数据。

2026-10-29 仅调整连线呈现：edge-path.js 在既有路由点上生成相切圆角，目标切线偏移为 14 屏幕像素，最多 80 世界单位且不超过相邻线段半长。圆弧对卡片和其他关系标签做完整矩形相交检查；空间不足时缩小圆角，不以切进卡片为代价抹平拐点。可见线、底衬和命中区域使用同一路径，缩放更新圆角，单纯平移复用缓存。默认线宽保持 2–2.1 屏幕像素，箭头为 7.5 屏幕像素，原有颜色、虚实线和方向含义保留。此处理不改节点坐标、相机、分组、关系筛选或笔记数据。

标签显示关系类型和简短说明；鼠标悬停或 Tab 聚焦连线可读起点、终点及完整说明。并列使用无箭头虚线，前置使用有箭头虚线；图例共享实际关系定义，不依赖排列序号猜线型。标签统一保持横向，在全部路线完成后避让卡片、其他线和已有标签，尺寸与绘制一致。线上空间不足时尝试邻近偏移，并用浅色短引导线标识所属线路；引导线也参与避障。没有安全空间时保留隐藏原因，在“排版提示”及连线提示中可追溯，不静默丢失说明。全图边界包含外围线路、可见标签、引导线和归属分组。

路由先稳定分配端口，再统一考虑长度、弯折、交叉和共线占用，网格兜底使用相同代价。初次排线后最多重新考虑八条干扰较大的线路，只接受整体代价下降的候选；大图限制额外网格搜索成本。障碍检查包含端口到节点边缘的完整线路。不能解决时保留 obstructed 状态，以图上提示和连线说明通知用户；不承诺任意密集图零交叉或任意固定坐标均有无障碍路径。

专用通道与反馈候选也参与干扰比较，不再锁定有交叉的通道；绕行增加量受长度与折点预算限制。网格按连续共线长度及接点交叉计费，避免短网格边漏算压缩后的长重叠。小图可在共享端点侧尝试有限端口槽交换，只接受全图代价下降、没有新穿卡且可见标签不减少的方案；失败同时还原端口和路线。此过程只调整连接点和走线，不改端点身份、关系方向或卡片位置。

2026-10-29 增加连线取直：两端位于相向的卡片边缘时，在实际可用的共同区间内尝试对齐连接点，不再以32个画布单位的小偏差窗口作为限制。保留卡片边缘内距、相邻端口至少16个单位的间距和已有居中顺序端口；直线必须避开卡片及其安全边界，不能增加交叉、共线占用或被收起的说明数量，并且完整路线代价须下降。没有共同连接区间或必须绕障时保留原圆角路线。连接点不随缩放重新吸附，坐标、笔记及关系记录保持原样。

手动拖动调用原渲染流程实时更新路线；正常松开时使用 pointerup 的最终坐标再重算一次，之后才保存该视图，不调用 autoLayout、局部卡片整理或相机适配。取消拖动恢复原坐标和路线，不保存中间位置。合成回归同时覆盖真实指针事件处理、三层 SVG 路径一致性、缩放下的最终落点及无最终 pointermove 的快速释放。

graph-layout.js 的内容布局支持并列同层、多输入汇合、基础补充与短支路就近。2026-10-28 按“突出主要关系”的要求调整展示：默认保留全部科学联系，用准确的分组框表达明确归属；仅将同向、同端点的 sequence 合并到对应科学连线。graph-presentation.js 返回每条合并关系的代表边及原因，完整说明放在原有悬停提示中，已有“查看全部关系”恢复所有独立边。没有科学边的顺序、反向顺序、并列和独有科学反馈均保留。不会跨类型沿路径约简，也不会因一个模块有少量科学关系就隐藏整条后续学习链。无内部联系的目录星形默认保留归属线；不能准确分组时同样回退显式归属线。

安全的目录模块可作为组头置于成员上方：必须由一个模块的直接归属完整覆盖当前其他可见节点，且该模块本身不参与任何非归属关系。它的归属边不再占据科学DAG的层和跨列通道。模块若自身参与证据、前置或应用，仍按实际知识角色排布；分组边界包含模块卡片、所有成员和无正文补充节点，不能包进无关卡片或替多归属选择唯一父节点。

2026-10-27 回退强制单排与稀疏模块固定三列的特殊排布，统一依照内容关系分层。用户确认职责划分：Codex 笔记整理时结合教材审核并保存知识关系，App 自动整理只负责准确排版。试作的正文规则推断已撤下，不引入新 schema 或展示层临时关系，不调用在线模型。编号、相似度和空白占位不能作为科学依赖依据。

“自动整理”使用已保存的知识关系重新排布，并可撤销；“仅整理连线”保留坐标。“重新排版（先预览）”仍可先查看效果。卡片右上角的位置锁定入口和状态圆点已移除；旧保存视图中的位置保留，旧锁定约束不再从磁盘恢复。“全图”按完整几何边界计算缩放，不再用12%的下限裁掉较宽图。

computeIncrementalLayout 仍保留有界局部调整的底层能力；placeAdditionalNodes 只放新节点，全部旧坐标保持精确不变。没有局部可行解时保留坐标并报告，不逐次逼近超出移动范围的目标。预览取消恢复原位置、模式和相机，应用后可撤销。预览前刷新未完成的视口保存，候选坐标不能落盘。

KnowledgeGraph 恢复按主题/模块持久保存的视图，不使用旧 note.position 改写正文。首次无视图时生成布局；之后正文、选择和关系变化不重排旧卡片，新卡片在关联空位补入。模块外卡片自动带入和一跳展开保持移除。跨模块连接仍保留在数据与总览中。小图适配，大图默认保留可读缩放，并提供“全图”。使用实际画布尺寸恢复相机；线宽与箭头保持屏幕尺寸，连线颜色与线型同步图例。整个流程只保存应用偏好，不修改 notebook 的节点、边、来源、状态或修改时间，也不调用外部语言模型。

几何回归测试位于 tests/edge-routing.test.mjs；自动布局与生命周期验证分别在 tests/graph-layout.test.mjs、tests/graph-auto.test.mjs，通过 scripts/run-tests.mjs 在明确范围的源码副本中运行。浏览器合成图测试使用项目任务目录独立源码和数据；真实页面检查以只读方式进行并核对前后笔记对象一致。

## 参考案例与采用边界

- [yFiles分组图](https://docs.yworks.com/yfiles-html/dguide/layout-grouping/)：用容器表达归属，不重复铺设父模块到每个成员的长箭头。
- [yEd分层布局](https://yed.yworks.com/support/manual/layout/layout_hierarchic_incremental.html)：按主方向和真实输入分层，保持并列与汇合；本轮不引入新的布局库或控制面板。
- [Obsidian图视图](https://obsidian.md/help/plugins/graph)：借鉴概览和完整联系的阅读尺度区分，复用现有完整关系入口。
- [Graphviz传递约简](https://graphviz.org/docs/cli/tred/)：图论可达性不能代替知识语义判断。本应用不将内容归属、前置、应用和证据混为同一可传递关系，不用它删减已审核科学边。
