# 笔记

独立的本地学习笔记应用。支持主题、关系图、Markdown 与常用公式、正文图片、搜索和备份。笔记、图片、持久草稿、偏好及默认导出保存在应用根目录内；应用不需要账户，不做云托管或跨设备同步。

笔记正文按保存的顺序连续呈现，不按“附图”或“推导与展开”等标题自动折叠。开头可先恢复问题与思路，再在推理处结合公式、配图和辨析；页内目录只滚动本页。图片可放大、恢复原始大小并拖动查看。知识连接及其已有说明可直接阅读，完整来源记录按需展开。

## 使用

先安装仍受支持的 Node.js LTS（最低 Node.js 22，推荐 Node.js 24 LTS）。Windows 上双击根目录的 **启动笔记.cmd**，浏览器打开 `http://127.0.0.1:4317`。结束前确认界面显示“已保存在本地”，再双击 **停止笔记.cmd**。当前版本没有 EXE 安装包；启动器不会下载 Node 或修改全局设置。

其他系统或终端可在应用目录执行：

```sh
npm start
```

这时服务在前台运行，按 `Ctrl+C` 停止。没有需要安装的第三方运行依赖。首次使用仅有源码的副本时，应用会创建空白笔记库；已有 `data` 会继续使用。分享源码不会分享自己的笔记。

## 目录分区

| 位置 | 用途 | 是否进入源码仓库 |
| --- | --- | --- |
| `src/server.mjs` | 本地 HTTP 服务与接口 | 是 |
| `src/lib/` | 笔记和图片的文件存储 | 是 |
| `src/public/` | 网页、样式、图标与前端逻辑 | 是 |
| `scripts/` | 启停、测试工作区和维护脚本 | 是 |
| `tests/` | 自动测试、合成数据和浏览器辅助工具 | 是 |
| `config/` | 可公开的默认配置 | 是 |
| `docs/` | 使用和开发说明 | 是 |
| `data/` | 个人笔记、图片、备份、归档、草稿、偏好与导出 | 忽略 |
| `runtime/` | 本机进程记录、启动锁和运行日志 | 默认忽略 |
| `成果产出/` | 本地报告与验证截图 | 默认忽略 |
| `_workspace/` | 本应用的任务、测试副本、临时文件和工具缓存 | 忽略 |

根目录的 `server.mjs`、`launch.ps1`、`stop.ps1` 是兼容入口；实际实现分别在 `src` 和 `scripts`。两份中文快捷命令继续调用根入口。

## 数据与备份

持续使用的数据文件是 `data/notebook.json`，图片在 `data/images/`。助手工作规范由研究项目独立管理，应用不存储、读取或展示这些规范。

默认导出保存在 `data/exports/`；浏览器用于查看界面，不再作为持久草稿、偏好或默认导出的存储位置。界面中的 JSON 导出包含笔记和引用的图片，**不包含草稿或偏好**。完整迁移个人数据时，先保存并停止应用，再备份整个 `data/`。`runtime/` 是本机运行记录，不需要带到另一台电脑。备份与原件留在同一磁盘不能防止磁盘故障，需要时另行复制到自己的备份介质。

## 学习框架

主题包含带有“框架模块”标签的节点时，关系图先显示模块总览。点击模块或使用“展开学习模块”下拉框，可查看对应知识节点；“返回总览”回到完整主线。模块之间用前置、应用或延伸等关系说明联系，模块内部的分支表示内容归属。

未学习节点可带有“框架节点”标签并保持正文为空，页面显示“待学习”。填写正文和手动更新学习状态后，模块进度随之更新。空模块和待学习节点不会被计作已有正文笔记，最近更新优先呈现有正文的记录。普通主题继续使用原有关系图。

关系图依据已保存的连接排布，支持同级并列、多输入汇合和反馈。默认突出实际知识关系：明确的模块归属用分组表达；同向、同端点的学习顺序并入对应科学连线，悬停可读两种含义。没有对应科学关系的顺序线保留，纯目录也不会变成无连接卡片。既有菜单“查看全部关系”可恢复逐条显示。知识关系由笔记整理助手结合正文与教材审核，通过版本接口保存；App 不从正文猜测或改写关系。阅读路线栏、卡片锁定入口和状态圆点继续移除。

## 布局保存与关系图可视范围

关系图按主题和展开模块独立保存节点位置、平移与缩放。重新进入恢复已保存的视图；增删关系或笔记时保留现有卡片位置，只有新增卡片放入空白区域，移除的卡片退出视图。修改标题、正文或学习状态也不会重排。拖动节点、平移或缩放后保存到本机 data 中，不写回笔记正文和学习状态。

手动拖动卡片时，相关连线随位置实时重算；松开后按最终落点再校正一次，无需点击“自动整理”。相向卡片边缘有可用的共同区间时优先取直，不能安全取直时保留必要圆角转折。这个过程保留你拖到的位置，不移动其他卡片，也不更改知识关系。

“自动整理”按当前模块已保存的知识关系重新排布，可从菜单撤销。新增卡片先找相关卡片附近的空位；重新进入仍恢复手工位置。按钮旁菜单提供“仅整理连线”和“重新排版（先预览）”，后者应用后才保存。其余模块不变，已有大图可用“全图”查看全貌。

内容布局优先处理已有的前置、应用、依据与并列关系。模块画布仅显示本模块内容，“模块外联系”展开功能已移除；跨模块的原始知识关系保留在笔记库和框架总览中。不能解决的卡片冲突、受阻连线和暂收起的说明会显示在“排版提示”中。反馈关系默认保留，自动整理不根据标题编号生成科学依赖，也不改写知识关系。

已审核的内容联系先决定层次，再安排卡片和连线；不强制所有卡片单排，也不套固定三列。纯目录的模块卡片置于组头，不再单独占据一整列，也不为已分组的归属扇出预留长线通道。前置与后续内容向右展开，并列支路在上下分开，多路输入与反馈保留，不因存在间接路径就删掉直接科学联系。缺少内容依据时保留已有目录与连接，由笔记整理流程补全。长图可横向拖动查看，“全图”展示整体结构。

侧栏右边的分隔条可左右拖动，主题工具栏下方的分隔条可上下拖动。收窄侧栏或缩短顶部区域可扩大关系图画布；侧栏足够窄时显示导航图标，顶部区域缩短时保留工具栏。关系图随画布尺寸适配。

松手后尺寸作为应用偏好保存在 `data/`；刷新和切换主题会恢复设置。双击某条分隔条可单独恢复该分区的默认布局。分隔条也支持键盘方向键、Home和End，拖动中按Esc可取消。窄窗口继续使用侧栏菜单；专注阅读时隐藏图上方的分隔条。布局设置不包含在笔记JSON备份中，也不修改笔记正文、状态或节点坐标。

## 继续开发

```sh
npm test
```

测试入口逐文件复制公开源码白名单（`src`、`scripts`、`tests`、`config`、`docs` 与固定根文件），在独立副本中运行自动检查；不复制个人数据和运行文件。默认输出在本应用 `_workspace/tasks/`。`NOTES_WORKSPACE_ROOT` 仅可指向本应用 `_workspace/` 内部路径，越界和符号链接会被拒绝，不读取父项目的工作区。

Windows 开发任务可先点调用 `scripts/Start-Task.ps1 -TaskName <任务名>`；续接任务可用 `-ResumeTask <目录名>`。它只设置当前进程的临时和缓存目录，所有目录仍在本应用 `_workspace/` 内。

分享程序前运行 `npm run prepare:release`，工具逐项审核 `config/release-files.json` 中的明确文件清单，拒绝未列入的源码文件、链接、环境文件、私有目录及未知文件类型；在 `_workspace/` 中生成仅含源码的 `source/` 和 SHA-256 清单。新增公共源码时须人工更新该清单。核验候选后，才将候选源码用于 GitHub 仓库或分享包。`.gitignore` 不能替代发布清单或清除既有 Git 历史；不要上传整个日常运行目录。本步骤不创建 Git 仓库、不上传，也未代选许可证。

详细说明见 [使用指南](docs/user-guide.md)、[开发与目录管理](docs/development.md) 和 [开发约定](AGENTS.md)。
